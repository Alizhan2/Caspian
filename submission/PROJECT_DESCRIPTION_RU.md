# Caspian Guardian AI

## Краткое описание

Caspian Guardian AI - веб-платформа для спутникового скрининга потенциальных нефтеподобных аномалий в Каспийском море. Она помогает экологам и операторам быстрее определить участки, которым нужна полевая проверка.

Платформа получает последние доступные SAR-сцены Sentinel-1, анализирует каналы VV/VH локальной open-source моделью или экспериментальным SAR-baseline, формирует геополигоны кандидатов и передаёт их в центр операторской проверки.

Важно: результат является экспериментальным screening signal, а не подтверждённым нефтяным разливом. Подтверждение требует проверки специалистом и полевых данных.

## Что реализовано в MVP

- Поиск реальных Sentinel-1 GRD сцен через публичный Earth Search STAC; доступен дополнительный Copernicus OAuth/Process API.
- Обработка VV/VH, локальный open-source U-Net/ResNet34 runtime и прозрачный экспериментальный SAR-baseline при отсутствии валидированных весов.
- AOI-мониторинг территорий, очередь Celery/Redis и статусы обработки от DISCOVERED до REVIEW.
- PostGIS для сцен, AOI, задач и полигонов; MinIO для растров, масок и превью.
- Береговая маска, фильтры площади/формы, сравнение сцен, опциональный авторизованный AIS-контекст и ручная верификация.
- Интерфейс на русском и казахском языках, карта, GeoJSON и PDF-отчёты.

## Практическая ценность

Решение не заменяет экологическую экспертизу. Оно сокращает путь от появления новой спутниковой сцены до приоритизированной задачи для оператора: где посмотреть снимок, какие контуры проверить и какие доказательства учесть.

## Технологии

React, TypeScript, Leaflet, FastAPI, Celery, Redis, PostGIS, MinIO, Sentinel-1, STAC, Copernicus Data Space, Python, Rasterio, GeoPandas, segmentation-models-pytorch, Ollama (опционально).

## Репозиторий и запуск

GitHub: https://github.com/Alizhan2/Caspian

Полная инструкция запуска находится в корневом README репозитория. Минимальный запуск выполняется через Docker Desktop:

```powershell
Copy-Item .env.example .env
docker compose up --build
```

После запуска интерфейс доступен на `http://localhost:5173`, API-документация - на `http://localhost:8000/docs`.
